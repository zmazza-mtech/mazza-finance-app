# Mazza Finance — mobile design

`Mazza Finance Mobile.dc.html` — open it in a browser. All five screens; the bottom tab bar switches between them. Tap a calendar day to raise the detail sheet.

`ios-frame.jsx` and `support.js` are needed for it to render. `ios-frame.jsx` only draws the phone bezel for presentation — it is not app code.

The mobile spec (tokens, per-screen layout, breakpoint rules) is in the `README.md` of the full handoff bundle, under **Mobile (≤ 640px)**.

Reference size: 393 × 852 (iPhone). Every button, chip and toggle is at least 44px; list rows are 56px.
